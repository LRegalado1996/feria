# A direct Sentry capture that bypasses the reporting helpers
#
# `captureExceptionWithScope` and `reportError` are what attach the action, procedure and request id, decide what is not an issue, and return an event id only when one was sent. A bare `captureException` produces an event with none of that, and from a callback outside the request scope nothing else will tag it either. Held at zero from the day the ratchet was added.

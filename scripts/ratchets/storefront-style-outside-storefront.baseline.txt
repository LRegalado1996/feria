# A storefront style used outside the storefront
#
# The storefront has its own visual language (design.md § Storefront): a display face set uppercase, fluid sizes, a marquee, and the five store colors a store overrides on its own pages. The admin keeps the calm back-office rules, which ban all-caps labels and moving bands. These utilities are allowed only in storefront components (a `store-` directory in a component tier) and storefront routes, so the two languages cannot leak into each other one class at a time.
